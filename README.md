# Dotfiles

My dotfiles.

## Quick Start

```sh
./install.sh
```

This installs the terminal setup in this repo for Linux or macOS and links the managed config files into place.

For Ubuntu Server or Proxmox console VMs:

```sh
./install-server.sh
```
